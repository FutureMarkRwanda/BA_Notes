## **1. Introduction to Arduino UNO**

### What is Arduino?

* Arduino is a **microcontroller development board** that reads inputs (e.g., sensors) and controls outputs (e.g., motors, LEDs) using code.
* It acts as the **brain** of robots and embedded systems, like a thermostat or a robotic vacuum.

### Why Arduino?

* **Beginner-friendly**: Simple to program and connect.
* **Open source**: Free software and community support.
* **Hands-on learning**: Ideal for understanding how robotics and electronics work.

### Arduino UNO Overview:

* **Digital Pins (2–13)**: For on/off signals (e.g., buttons, LEDs).
* **PWM Pins (3, 5, 6, 9, 10, 11)**: Simulate analog output for controlling motor speed or LED brightness.
* **Analog Pins (A0–A5)**: Read variable signals from sensors (e.g., temperature).
* **Power Pins**: 5V, GND for powering circuits.

**Visual Aid**: Imagine the Arduino UNO as a small computer with numbered pins. A pinout diagram (available online or in the Arduino IDE) shows which pins are digital, PWM, or analog.

## **2. Microcontroller vs Microprocessor**

| Feature                | Microcontroller                  | Microprocessor                        |
| ---------------------- | -------------------------------- | ------------------------------------- |
| Includes RAM, ROM, I/O | Yes – all in one chip            | No – needs external RAM, I/O          |
| Used In                | Robotics, IoT devices            | Laptops, smartphones                  |
| Example                | Arduino (ATmega328), ESP32       | Intel Core i7, Apple M1               |
| Purpose                | Controls specific tasks (e.g., motor speed) | Runs complex systems (e.g., operating systems) |

### Key Concept:

**Microcontrollers** handle real-time tasks, like making a robot move. **Microprocessors** power general-purpose devices, like your computer.

## **3. How Arduino Code Works**

### Structure of an Arduino Sketch:

```cpp
void setup() {
  // Runs once to initialize (e.g., set up pins)
}

void loop() {
  // Runs repeatedly to control the system
}
```

* `setup()`: Configures pins or starts communication (e.g., Serial).
* `loop()`: Runs continuously, like a heartbeat, to check inputs or control outputs.

### Example 1 – Blinking LED:

This code makes an LED on pin 8 blink every 500ms.

```cpp
void setup() {
  pinMode(8, OUTPUT); // Set pin 8 as an output for the LED
}

void loop() {
  digitalWrite(8, HIGH); // Turn LED on (5V)
  delay(500); // Wait 500ms
  digitalWrite(8, LOW); // Turn LED off (0V)
  delay(500); // Wait 500ms
}
```

**How It Works**:
- `pinMode(8, OUTPUT)` sets pin 8 to send signals.
- `digitalWrite(8, HIGH)` sends 5V to turn the LED on; `LOW` sends 0V to turn it off.
- `delay(500)` pauses for 500 milliseconds.

**Try It**: Change the delay to 200ms. How does the blinking speed change?

### Example 2 – Serial Output:

This code prints a message to the Serial Monitor every second.

```cpp
void setup() {
  Serial.begin(9600); // Start Serial communication at 9600 baud rate
}

void loop() {
  Serial.println("Hello, Robot!"); // Print message
  delay(1000); // Wait 1 second
}
```

**How It Works**:
- `Serial.begin(9600)` starts communication with your computer.
- `Serial.println()` sends text to the Serial Monitor (view in Arduino IDE).
- `delay(1000)` pauses for 1 second.

## **4. Digital vs Analog in Arduino**

| Concept     | Digital                       | Analog                               |
| ----------- | ----------------------------- | ------------------------------------ |
| Signal Type | ON/OFF (1 or 0)               | Continuous range (0–1023)            |
| Read With   | `digitalRead(pin)`            | `analogRead(pin)`                    |
| Write With  | `digitalWrite(pin, HIGH/LOW)` | `analogWrite(pin, value)` (PWM only) |
| Examples    | Buttons, LEDs                 | Potentiometers, temperature sensors  |

**Digital**: Like a light switch (on or off). Used for simple decisions.
**Analog**: Like a dimmer knob. Measures or controls a range (e.g., motor speed).

## **5. Role of PWM (Pulse Width Modulation)**

### What is PWM?

* PWM **simulates analog output** by rapidly turning a digital signal on and off.
* The **duty cycle** (percentage of "on" time) controls speed or brightness.

**Analogy**: Imagine flicking a light switch on/off quickly to mimic dimming. Longer "on" times make the light brighter.

### Where It’s Used:

* Adjusting **motor speed** in robots.
* Dimming **LEDs** in displays.

## **6. Adafruit Motor Shield: Purpose and Wiring**

![](https://protosupplies.com/wp-content/uploads/2018/04/L293D-V1-Motor-Driver-Shield-1.jpg)
### Why Use a Motor Shield?

* Arduino’s pins cannot directly power motors due to limited current.
* The **Adafruit Motor Shield** simplifies motor control by:
  * Using an **external battery** for motor power.
  * Controlling **motor direction** (forward/reverse).
  * Adjusting **speed** using PWM.
  * Supporting up to **four DC motors** or two stepper motors via a plug-and-play shield.

### Wiring Summary:

* **Motor Ports (M1, M2, M3, M4)**: Connect DC motor wires to the terminal blocks (e.g., M1 for Motor 1).
* **Power Jumper**: Keep the power jumper on if powering Arduino via USB; remove it and connect an external 5V–12V power supply (e.g., 9V battery) to the power terminal for motors.
* **GND**: Connect the ground of the external power supply to the shield’s ground terminal.
* **Arduino Connection**: Stack the shield onto the Arduino UNO, aligning all pins.
* **Library**: Use the **Adafruit Motor Shield V2 library** (install via Arduino IDE) for easy control.

**Safety Note**:
- Ensure correct polarity when connecting the battery to avoid damaging the shield or Arduino.
- Use a 7.4V–12V power supply within the shield’s limits (check motor requirements).
- Disconnect power when wiring to prevent short circuits or electric shock.
- Double-check motor connections to the terminal blocks to ensure they are secure.

**Note**: The Adafruit Motor Shield uses I2C communication (pins A4 and A5) for control, leaving most digital and PWM pins free for other uses.

## **7. Hands-On Activity (Time: 60–75 minutes)**

### Objective:

Use Arduino UNO and Adafruit Motor Shield to control a DC motor’s **direction** and **speed**, and test LED/Serial output. Build a simple chassis for future use.

### Materials Per Group:

* Arduino UNO
* Adafruit Motor Shield V2
* DC motor + wheels
* Battery (7.4V Li-ion or 9V)
* Jumper wires
* Breadboard (optional)
* Cardboard chassis or platform
* Laptop with Arduino IDE

### Part 1: Blink an LED (10 min)

```cpp
void setup() {
  pinMode(8, OUTPUT); // Set pin 8 as output
}

void loop() {
  digitalWrite(8, HIGH); // LED on
  delay(500); // Wait 500ms
  digitalWrite(8, LOW); // LED off
  delay(500); // Wait 500ms
}
```

**Troubleshooting**:
- LED doesn’t light? Check wiring (anode to pin 8, cathode to GND via resistor).
- Use a 220Ω resistor to protect the LED.

### Part 2: Display a Message in Serial Monitor (10 min)

```cpp
void setup() {
  Serial.begin(9600); // Start Serial at 9600 baud
}

void loop() {
  Serial.println("Motor starting..."); // Print message
  delay(1000); // Wait 1 second
}
```

**Troubleshooting**:
- No output in Serial Monitor? Ensure the correct COM port is selected in Arduino IDE.

### Part 3: Control Motor Direction and Speed (20 min)

```cpp
#include <AFMotor.h>

// Initialize motors
AF_DCMotor leftMotor(1); // Motor on M1 port
AF_DCMotor rightMotor(2); // Motor on M2 port

void setup() {
  Serial.begin(9600); // Start Serial
  leftMotor.setSpeed(180); // Set left motor speed (0–255)
  rightMotor.setSpeed(180); // Set right motor speed (0–255)
}

void loop() {
  // Forward
  Serial.println("Motor Forward");
  leftMotor.run(FORWARD);
  rightMotor.run(FORWARD);
  delay(2000); // Run for 2 seconds

  // Reverse
  Serial.println("Motor Reverse");
  leftMotor.run(BACKWARD);
  rightMotor.run(BACKWARD);
  delay(2000); // Run for 2 seconds
}
```

**Troubleshooting**:
- Motor doesn’t spin? Check battery charge, motor connections to M1, and ensure the library is installed.
- Motor spins one way only? Verify the code uses `FORWARD` and `BACKWARD` correctly.
- Install the Adafruit Motor Shield V2 library via Arduino IDE’s Library Manager.

### Part 4: Mount Motors and Wheels (20–25 min)

* Attach motors to a cardboard chassis using tape or screws.
* Connect wheels to motors.
* Test motor direction and adjust wiring if needed.
* Ensure the chassis is stable for future sensor additions.

**Tip**: Keep wires tidy to avoid disconnections during testing.

## **9. Glossary of Key Terms**

* **Microcontroller**: A small computer on a chip that controls specific tasks (e.g., Arduino).
* **PWM (Pulse Width Modulation)**: A technique to simulate analog output by varying digital pulse width.
* **Serial Communication**: A way to send data between Arduino and a computer (e.g., Serial Monitor).
* **pinMode()**: Sets a pin as input or output.
* **Adafruit Motor Shield**: A shield that simplifies DC motor control using a library and I2C communication.
