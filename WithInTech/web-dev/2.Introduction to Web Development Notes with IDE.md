## 2. Tools for Web Development
**Objective**: Introduce local and online tools, including what an IDE is, for coding, testing, and learning.

### What is an IDE?
An **Integrated Development Environment (IDE)** is a software application that combines tools for writing, editing, debugging, and testing code in one place. Think of it as a "supercharged" text editor with features like code suggestions, error highlighting, and live previews, making coding easier and faster. Unlike basic text editors (e.g., Notepad), IDEs are designed for developers and support multiple programming languages like HTML, CSS, and JavaScript.

**Example**: Visual Studio Code (VS Code) is a popular IDE for web development because it’s free, customizable, and supports extensions like Live Server for real-time web page previews.

### Local Tools
Installed on your computer for a robust coding experience:
- **IDE**:
  - **[Visual Studio Code (VS Code)](https://code.visualstudio.com/)**:
    - *Why use it?* Lightweight IDE with code completion, debugging, and extensions (e.g., Live Server for instant previews).
    - *Setup*: Download, install, and add the “Live Server” extension.
  - **[WebStorm](https://www.jetbrains.com/webstorm/)**:
    - *Why use it?* Advanced IDE with powerful features for web development (paid, but free trial).
- **Text Editors** (simpler than IDEs):
  - **[Sublime Text](https://www.sublimetext.com/)**: Fast, lightweight for quick edits.
    - *Why use it?* Simple interface, great for beginners.
- **Browsers**:
  - **Google Chrome**, **Mozilla Firefox**: Test web pages and use Developer Tools (F12) to inspect HTML/CSS.
    - *Why use them?* Chrome’s DevTools highlight errors; Firefox supports accessibility testing.
- **File Management**:
  - Create a folder (e.g., `web-dev-projects`) for `.html` files.
  - Use names like `index.html` for main pages.

### Online Tools
Code in your browser without installation:
- **[CodePen](https://codepen.io/)**: Online editor for HTML, CSS, JavaScript with live previews.
  - *Why use it?* Ideal for quick experiments and sharing.
- **[JSFiddle](https://jsfiddle.net/)**: Test small code snippets.
  - *Why use it?* Easy debugging and sharing.
- **[Replit](https://replit.com/)**: Online IDE for full projects.
  - *Why use it?* Supports collaboration and hosting.
- **Learning Resources**:
  - **[W3Schools](https://www.w3schools.com/html/)**: Free HTML tutorials.
  - **[MDN Web Docs](https://developer.mozilla.org/en-US/docs/Web/HTML)**: Detailed web dev reference.
  - **[Flaticon](https://www.flaticon.com/)**: Free icons for favicons.

**Practice** (10 minutes):
1. **Local Setup**:
   - Download VS Code (an IDE).
   - Create a `web-dev-projects` folder and `index.html` file.
   - Write `<h1>Hello, World!</h1>`, save, and open with Live Server in Chrome.
2. **Online Setup**:
   - Visit CodePen, create a “Pen,” and write `<p>Test paragraph</p>`.
   - Save and view the output.
3. Share one feature you like about VS Code or CodePen (e.g., live preview, code suggestions).

## 3. Intro to Website Development
**Objective**: Explain websites and frontend vs. backend.

### What is a Website?
A website is a collection of web pages accessible via the internet, displayed in a browser—like a digital book for reading or interacting (e.g., shopping, booking).

### How Does a Website Work?
- **Client-Server Model**:
  - **Client**: Your device requests a page via a browser.
  - **Server**: Sends files (HTML, CSS, JS).
  - **Browser**: Renders files into a page.
- **Components**:
  - **Frontend**: User interface (text, buttons).
  - **Backend**: Logic and data (databases, logins).

### Frontend vs. Backend
| Aspect       | Frontend                            | Backend                             |
|--------------|-------------------------------------|-------------------------------------|
| **Focus**    | User interface, visuals            | Server, database, logic             |
| **Tech**     | HTML, CSS, JavaScript              | Python, Node.js, SQL                |
| **Example**  | A “Submit” button                  | Saving form data                    |

**Diagram**: Frontend vs. Backend

```
[User] --> [Browser (Frontend: HTML, CSS, JS)] --> [Server (Backend: Database, Logic)]
```

**Analogy**: A website is like a restaurant—frontend is the dining area, backend is the kitchen.

## 4. Web Page Structure (HTML Layout)
**Objective**: Learn HTML’s foundational structure.

### What is HTML?
HTML (HyperText Markup Language) defines a web page’s structure using tags (e.g., `<p>` for paragraphs).

### Basic HTML Structure
- `<!DOCTYPE html>`: Declares HTML5.
- `<html>`: Root element.
- `<head>`: Metadata (title, favicon).
- `<body>`: Visible content.

**Example**:
```html
<!DOCTYPE html>
<html>
<head>
    <title>My Web Page</title>
</head>
<body>
    <h1>Welcome!</h1>
    <p>This is my first web page.</p>
</body>
</html>
```

**Diagram**: HTML Structure

```
[<!DOCTYPE html>]
    └── [html]
         ├── [head]
         │   └── (title, favicon, metadata)
         └── [body]
             └── (headings, paragraphs, links, lists)
```

**Practice**:
1. In VS Code or CodePen, create `index.html`.
2. Write the HTML structure above.
3. Open in a browser to see “Welcome!” and a paragraph.

## 6. Head Elements: Title & Favicon
**Objective**: Understand `<head>` elements.

### Key Head Elements
- `<title>`: Browser tab title.
  - Example: `<title>My Site</title>`
- `<link>`: Links a favicon (tab icon).
  - Example: `<link rel="icon" href="favicon.ico">`
- `<meta>`: Metadata (e.g., encoding).
  - Example: `<meta charset="UTF-8">`

**Example**:
```html
<head>
    <title>My First Website</title>
    <link rel="icon" href="https://example.com/favicon.ico">
    <meta charset="UTF-8">
</head>
```

**Practice**:
1. Add `<title>` (e.g., “My Page”) to `index.html`.
2. Download a favicon from [Flaticon](https://www.flaticon.com/) and link it.
3. Add `<meta charset="UTF-8">` and test in a browser.

## 7. Basic Body Tags: p, h1–h6, a, br, b, i
**Objective**: Learn content creation tags.

### Common Tags
- `<p>`: Paragraph.
  - Example: `<p>I love coding!</p>`
- `<h1>` to `<h6>`: Headings.
  - Example: `<h1>Title</h1>`, `<h3>Subheading</h3>`
- `<a>`: Link.
  - Example: `<a href="https://google.com">Google</a>`
- `<br>`: Line break.
  - Example: `<p>Line 1<br>Line 2</p>`
- `<b>`: Bold.
  - Example: `<b>Important</b>`
- `<i>`: Italic.
  - Example: `<i>Emphasis</i>`

**Example**:
```html
<body>
    <h1>About Me</h1>
    <p>I’m learning <b>web development</b>!</p>
    <p>Visit my <a href="https://github.com">GitHub</a>.</p>
    <p>Hobbies:<br>Coding<br>Reading</p>
</body>
```

**Practice**:
1. Add `<h1>` and `<p>` to `index.html`.
2. Include an `<a>` link.
3. Use `<br>`, `<b>`, or `<i>` for formatting.

## 8. Lists in HTML: ul, ol, li
**Objective**: Create ordered/unordered lists.

### Types of Lists
- `<ul>`: Unordered (bullets).
  - Example: `<ul><li>Item 1</li><li>Item 2</li></ul>`
- `<ol>`: Ordered (numbers).
  - Example: `<ol><li>Step 1</li><li>Step 2</li></ol>`
- `<li>`: List item.
- **Nesting**: Add `<ul>` or `<ol>` inside `<li>`.

**Example**:
```html
<h2>My Skills</h2>
<ul>
    <li>HTML
        <ul>
            <li>Tags</li>
            <li>Lists</li>
        </ul>
    </li>
    <li>Coding</li>
</ul>
<h2>Learning Steps</h2>
<ol>
    <li>Learn HTML</li>
    <li>Learn CSS</li>
</ol>
```

**Practice**:
1. Add a `<ul>` with 3 hobbies.
2. Add an `<ol>` with 3 learning steps.
3. Nest a `<ul>` inside an `<li>`.
