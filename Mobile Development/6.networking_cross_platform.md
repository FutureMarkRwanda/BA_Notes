# Networking in Cross-Platform Development

## Overview

Networking is a core part of modern mobile applications, enabling apps to retrieve and send data from/to external servers and APIs. In React Native, developers typically use the built-in `fetch()` API or third-party libraries like `axios` to perform HTTP requests.

---

## Fetching Data from APIs

### **1. Using `fetch()` (Native JavaScript API)**

* Built into the JavaScript runtime.
* Supports asynchronous requests using Promises or `async/await`.
* Requires manual error and JSON handling.

**Example:**

```javascript
import React, { useState, useEffect } from 'react';
import { FlatList, Text, View, ActivityIndicator } from 'react-native';

export default function DataList() {
  const [data, setData] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetch('https://api.example.com/movies')
      .then(response => response.json())
      .then(json => {
        setData(json);
        setLoading(false);
      })
      .catch(error => {
        console.error(error);
        setLoading(false);
      });
  }, []);

  if (loading) {
    return <ActivityIndicator size="large" />;
  }

  return (
    <FlatList
      data={data}
      keyExtractor={(item) => item.id.toString()}
      renderItem={({ item }) => <Text>{item.title}</Text>}
    />
  );
}
```

---

### **2. Using Axios (Third-Party Library)**

* Offers cleaner syntax and automatic JSON parsing.
* Provides advanced features like request/response interceptors and custom headers.
* Preferred for larger applications.

**Installation:**

```bash
npm install axios
```

**Example:**

```javascript
import React, { useState, useEffect } from 'react';
import { FlatList, Text, View, ActivityIndicator } from 'react-native';
import axios from 'axios';

export default function DataList() {
  const [data, setData] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    axios.get('https://api.example.com/movies')
      .then(response => {
        setData(response.data);
        setLoading(false);
      })
      .catch(error => {
        console.error(error);
        setLoading(false);
      });
  }, []);

  if (loading) {
    return <ActivityIndicator size="large" />;
  }

  return (
    <FlatList
      data={data}
      keyExtractor={(item) => item.id.toString()}
      renderItem={({ item }) => <Text>{item.title}</Text>}
    />
  );
}
```

## Progress Indicators (Optional but Recommended)

Showing loading indicators improves user experience while fetching or uploading data.

### Example using `react-native-progress`:

```bash
npm install react-native-progress
```

```javascript
import * as Progress from 'react-native-progress';

export default function Loader({ progress }) {
  return <Progress.Bar progress={progress} width={200} />;
}
```

### Alternative (Built-in):

```javascript
import { ActivityIndicator } from 'react-native';

<ActivityIndicator size="large" color="#0000ff" />
```

## Cross-Platform Compatibility

* Both `fetch()` and `axios` work seamlessly on **iOS** and **Android**.
* No need for platform-specific code unless endpoints or headers differ between platforms.
* Use `Platform.OS` if customization is necessary:

```javascript
import { Platform } from 'react-native';

const apiUrl = Platform.OS === 'android'
  ? 'https://android.api.example.com'
  : 'https://ios.api.example.com';
```

## Best Practices for Networking in React Native

| Best Practice                        | Description                                                               |
| ------------------------------------ | ------------------------------------------------------------------------- |
| **Use `try/catch` with async/await** | For cleaner error handling.                                               |
| **Handle loading states**            | Provide feedback using loaders/spinners.                                  |
| **Avoid hardcoding API URLs**        | Use `.env` files or configuration files.                                  |
| **Secure API keys**                  | Never store secrets in frontend code—use a backend proxy or secure vault. |
| **Paginate large results**           | Prevent performance issues by loading data in chunks.                     |
| **Debounce input requests**          | Useful in search fields to avoid flooding the server with requests.       |
| **Use caching**                      | Libraries like SWR or React Query can help cache API responses.           |

---

## Conclusion

React Native offers flexible and powerful options for working with APIs. While `fetch()` is built-in and perfectly capable for simple tasks, libraries like `axios` can simplify code and provide additional features for more complex networking needs. Using proper loading indicators, error handling, and secure practices is critical for delivering a reliable user experience across platforms.
