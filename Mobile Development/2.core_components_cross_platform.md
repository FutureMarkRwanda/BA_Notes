# Core Components for Cross-Platform Development

### **Overview**

React Native provides a unified set of **core components** that map directly to **native UI elements** on both iOS and Android. These components are essential for building mobile apps with **native performance and cross-platform consistency**, using a single JavaScript codebase.

---

## Key Core Components

| Component          | Purpose                                      | Native Equivalent (iOS / Android)   |
| ------------------ | -------------------------------------------- | ----------------------------------- |
| `View`             | Basic layout container (like `<div>` in web) | `UIView` / `View`                   |
| `Text`             | Displays strings of text                     | `UILabel` / `TextView`              |
| `Image`            | Renders images from local or remote sources  | `UIImageView` / `ImageView`         |
| `TextInput`        | Editable input field for forms               | `UITextField` / `EditText`          |
| `ScrollView`       | Scrollable container for large content       | `UIScrollView` / `ScrollView`       |
| `TouchableOpacity` | Pressable element with opacity feedback      | UIWrapper / Press handler           |
| `Alert`            | Displays alert dialogs                       | `UIAlertController` / `AlertDialog` |

---

### 1. View

A foundational component used for layout and styling.

```jsx
<View style={{ padding: 10, backgroundColor: 'lightblue' }} />
```

---

### 2. Text

Required wrapper for any string content in React Native.

```jsx
<Text style={{ fontSize: 20 }}>Hello, World!</Text>
```

---

### 3. Image

Supports local, remote, and base64 images.

```jsx
<Image
  source={{ uri: 'https://example.com/logo.png' }}
  style={{ width: 100, height: 100 }}
/>
```

---

### 4. TextInput

Used for collecting input from users (like forms or search bars).

```jsx
<TextInput
  placeholder="Enter your name"
  style={{ borderBottomWidth: 1, margin: 10 }}
  onChangeText={(text) => setName(text)}
/>
```

---

### 5. ScrollView

Scrolls vertically or horizontally through content.

```jsx
<ScrollView>
  <Text>Item 1</Text>
  <Text>Item 2</Text>
  <Text>Item 3</Text>
</ScrollView>
```

Note: Avoid nesting too many `ScrollView`s. Use `FlatList` or `SectionList` for long, performance-sensitive lists.

---

### 6. Touchable Components

For handling user interaction.

**TouchableOpacity (commonly used):**

```jsx
<TouchableOpacity onPress={() => alert('Pressed')}>
  <Text>Click Me</Text>
</TouchableOpacity>
```

**TouchableNativeFeedback (Android only):**

```jsx
<TouchableNativeFeedback onPress={() => console.log('Android Ripple')}>
  <View><Text>Press Here</Text></View>
</TouchableNativeFeedback>
```

---

### 7. Alert

Cross-platform pop-up dialogs.

```jsx
import { Alert } from 'react-native';
Alert.alert('Notice', 'This is a cross-platform alert', [{ text: 'OK' }]);
```

---

## Platform-Specific Handling

### Platform Module

Use platform detection for conditional rendering or styling:

```jsx
import { Platform } from 'react-native';

const background = Platform.OS === 'ios' ? 'red' : 'green';
```

### Platform-Specific Files

You can split logic or components by platform:

```
Button.ios.js
Button.android.js
```

React Native automatically resolves the correct file based on the platform.

---

## Layout System: Flexbox in React Native

React Native uses **Flexbox** (similar to CSS) for layout:

```jsx
<View style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}>
  <Text>Hello World</Text>
</View>
```

| Property         | Purpose                       |
| ---------------- | ----------------------------- |
| `flex`           | Determines space distribution |
| `justifyContent` | Aligns children vertically    |
| `alignItems`     | Aligns children horizontally  |

---

## Benefits of Using Core Components in React Native

* Cross-platform consistency: Components map to native controls on both platforms.
* Faster development: Shared logic, fewer files to maintain.
* Fine-grained customization: Platform-specific props and files enable customization.
* Native performance: Unlike hybrid apps (e.g., Cordova), React Native compiles into real native code.

---

## Conclusion

React Native core components provide a powerful toolkit for building mobile apps that look and feel native on both iOS and Android. Understanding these building blocks is essential for creating scalable, performant, and maintainable cross-platform applications.
