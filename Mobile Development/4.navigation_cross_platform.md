# Navigation in Cross-Platform Development

## Overview
Navigation in React Native enables seamless transitions between screens in a mobile application, critical for cross-platform apps with multiple screens. The `@react-navigation` library is widely used for this purpose.

## Key Concepts
- **NavigationContainer**: Wraps the entire app to manage navigation state.
  - Example:
    ```javascript
    import { NavigationContainer } from '@react-navigation/native';
    export default function App() {
      return (
        <NavigationContainer>
          {/* App screens */}
        </NavigationContainer>
      );
    }
    ```
- **Stack Navigator**: Provides a stack-based navigation system (e.g., push/pop screens).
  - Installation: `npm install @react-navigation/native @react-navigation/native-stack`
  - Example:
    ```javascript
    import { createNativeStackNavigator } from '@react-navigation/native-stack';
    const Stack = createNativeStackNavigator();

    export default function App() {
      return (
        <NavigationContainer>
          <Stack.Navigator>
            <Stack.Screen name="Home" component={HomeScreen} />
            <Stack.Screen name="Profile" component={ProfileScreen} />
          </Stack.Navigator>
        </NavigationContainer>
      );
    }
    ```
- **Navigation Prop**: Each screen component receives a `navigation` prop with methods like `navigate` to switch screens.
  - Example:
    ```javascript
    const HomeScreen = ({ navigation }) => (
      <Button
        title="Go to Profile"
        onPress={() => navigation.navigate('Profile', { name: 'Jane' })}
      />
    );
    const ProfileScreen = ({ route }) => (
      <Text>This is {route.params.name}'s profile</Text>
    );
    ```

## Cross-Platform Benefits
- Unified navigation logic works on both iOS and Android.
- Platform-specific styling (e.g., header appearance) can be customized using `Platform.OS` or navigator options.
- Supports advanced navigation patterns (e.g., tabs, drawers) for complex apps.

## Installation
- Install dependencies: `npm install react-native-screens react-native-safe-area-context`
- Wrap app in `NavigationContainer` for cross-platform compatibility.
