# Push Notifications in Cross-Platform Development

## Overview

Push notifications let mobile apps deliver messages, alerts, and updates to users—even when the app is closed. In React Native, you can use:

* **Expo Push Notifications** for unified, cross-platform support.
* **Native services** like **Firebase Cloud Messaging (FCM)** and **Apple Push Notification Service (APNs)** for fine-grained control.
* **Local and scheduled notifications** for offline reminders and user-driven alerts.

---

## Expo Push Notifications

### Setup

```bash
npm install expo-notifications
```

### Request Permissions and Register Token

```javascript
import * as Notifications from 'expo-notifications';
import { useEffect, useState } from 'react';
import { Platform } from 'react-native';

export default function App() {
  const [expoPushToken, setExpoPushToken] = useState('');

  useEffect(() => {
    const register = async () => {
      const { status } = await Notifications.requestPermissionsAsync();
      if (status !== 'granted') return;
      const token = await Notifications.getExpoPushTokenAsync();
      setExpoPushToken(token.data);
    };
    register();
  }, []);

  return null;
}
```

## Sending Notifications (Server-Side with Expo)

```javascript
const { Expo } = require('expo-server-sdk');
const expo = new Expo();

async function sendPushNotification(token, message) {
  const messages = [{
    to: token,
    sound: 'default',
    title: 'Hello!',
    body: message,
    data: { screen: 'Home' },
  }];
  const chunks = expo.chunkPushNotifications(messages);
  for (const chunk of chunks) {
    await expo.sendPushNotificationsAsync(chunk);
  }
}
```

## Native Push Notifications (FCM / APNs)

* **Android (FCM)**:

  * Add `google-services.json`
  * Use [`@react-native-firebase/messaging`](https://rnfirebase.io/messaging)
* **iOS (APNs)**:

  * Setup push key or certificates.
  * Configure with Xcode and Apple Developer portal.
* Use `react-native-push-notification` or `@notifee/react-native` for unified native control.

## Local Notifications

Local notifications are triggered on the device without a server.

```javascript
Notifications.scheduleNotificationAsync({
  content: {
    title: 'Reminder',
    body: 'Check your to-do list!',
  },
  trigger: { seconds: 5 },
});
```

### Use Cases:

* Reminders
* Alerts when offline
* Confirmation alerts (e.g., “Workout complete!”)

---

## Scheduled Notifications

Schedule notifications for the future (e.g., in 24 hours):

```javascript
Notifications.scheduleNotificationAsync({
  content: {
    title: 'Daily Summary',
    body: 'Check your progress today!',
  },
  trigger: { hour: 20, minute: 0, repeats: true }, // every day at 8 PM
});
```

## Deep Linking on Notification Tap

Navigate users to specific screens when they tap the notification.

```javascript
Notifications.setNotificationResponseReceivedListener(response => {
  const screen = response.notification.request.content.data.screen;
  if (screen) {
    navigationRef.current?.navigate(screen);
  }
});
```

> Ensure `navigationRef` is connected to your main `NavigationContainer` via `React.createRef()` or `useNavigationContainerRef()`.

## Best Practices

| Tip                                                     | Reason                                                  |
| ------------------------------------------------------- | ------------------------------------------------------- |
| Request notification permissions early but with context | Builds trust and avoids user rejection.                 |
| Use local notifications for reminders                   | No server needed, great for offline features.           |
| Schedule notifications responsibly                      | Avoid spamming the user or violating platform policies. |
| Handle notification taps cleanly                        | Ensure smooth navigation and a consistent UX.           |
| Monitor delivery and open rates                         | Use Expo or FCM analytics to measure effectiveness.     |
| Segment users for targeted messages                     | More relevance = better engagement and lower opt-outs.  |

---

## Conclusion

Push notifications are a powerful tool for improving user engagement and retention in cross-platform mobile apps. Whether you're using **Expo** for simplicity or **native services** for greater control, React Native makes it possible to send and manage notifications across platforms. Adding support for **local**, **scheduled**, and **deep-link-enabled** notifications enhances usability and keeps users informed—even offline.
